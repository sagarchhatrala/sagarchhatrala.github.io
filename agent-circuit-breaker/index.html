KNOW THE BOUNDARY

Clear answers.
Clear expectations.

What does UNKNOWN mean?

ACB could not establish that the action passed its supported checks. It is a separate result, not permission. RuntimeGate does not issue executable authority for an unknown action. ALLOW, BLOCK, UNKNOWN, PENDING_APPROVAL, and ERROR remain distinct outcomes.

Does ACB sandbox an entire agent?

No. ACB controls the paths that a trusted integration routes through it. Direct subprocess calls, arbitrary host processes, and compromised trusted executors remain outside that boundary. Use separate OS and network controls where your threat model requires them.

What is the supported deployment scope?

Version 1.7.2 is beta. The owner route requires Python 3.11+ and Linux/macOS. Protected deployment requires distinct UIDs, protected owner resources and control socket, and OS/network isolation that removes alternate access. The authority model remains single-host. Same-UID development, readiness checks, and configuration verification do not certify containment. Distributed coordination and exactly-once external effects remain outside scope.

How do the MCP server and legacy proxy differ?

The owner MCP client forwards typed requests to a separate owner process with approvals and effect budgets. The existing workflow-mcp server still executes its six typed tools through RuntimeGate with durable start/outcome tracking. The legacy proxy inspects calls before forwarding and does not own that execution lifecycle. Its HTTP mode is a custom JSON POST bridge, not full Streamable HTTP. See the adapter enforcement matrix for each entry point.

Can the agent run arbitrary SQL or export anywhere?

No. The owner registers parameterized SQLite UPDATE/DELETE operations on a supported single table and registers each S3 destination. Agents cannot supply raw SQL, substitute an upload URL, or grant themselves approval. Snapshot changes require fresh review. This is a bounded maintenance profile, not general SQL or ORM support.

What counts toward a budget?

The owner adapter counts created output files, affected SQLite rows, and S3 payload bytes. It reserves budget at execution start, including approved actions, and settles trusted measured effects. Reads, previews, MCP replies, network overhead, token usage, and monetary spend are not export-byte measurements. Uncertain effects retain their reservation after restart.

Does redaction make an artifact safe to publish?

Pattern redaction can miss sensitive content and deliberately preserves labels. Only the owner can inspect exact bytes and explicitly declassify a new artifact. Copies, encoding, JSON transformations, and redaction do not grant export permission.

Do I need to migrate an existing integration?

The owner route and effect budgets are opt-in. Existing unbudgeted RuntimeGate contracts keep their fingerprints; the evaluator, rule schema, legacy proxy, and original six-tool Workflow remain supported. Review the v1.7.1 notes for stricter MCP calls and signed-ledger migration.

Can I inspect the implementation and this demo’s evidence?

Yes. ACB is MIT-licensed. The interactive policy checks and approval walkthrough were recorded on November 11 from v1.7.2 source commit 7c04c39. Read the recorded results, structured project facts, or plain-text guide. The embedded video comes from the v1.7.0 release. Owner workflow checks come from the published v1.7.2 release reports.
