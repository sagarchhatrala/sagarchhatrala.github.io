Projects

Two projects, one security story.

Agent Circuit Breaker protects the immediate execution path. Horizon Agent Containment models what the agent is becoming capable of over time.

Production package
Agent Circuit Breaker A local-first runtime safety gate for AI agents, MCP tools, and coding workflows. It checks proposed commands, filesystem operations, SQL, tool calls, and trajectories before execution.
  • Pre-execution decisions for allow, block, unknown, error, and approval.
  • MCP proxy inspection, policy files, audit ledger, SARIF, and PyPI release.
  • Best when you need a control point before an agent acts.
Project sitePyPI
Research prototype
Horizon Agent Containment A deterministic containment prototype for long-horizon AI agents. It tracks state, provenance, authority, graph relationships, and emergent capabilities before allowing a transition.
  • Blocks capability emergence such as secret-derived data reaching an external destination.
  • Models provenance, trust boundaries, explicit delegation, and non-transitive authority.
  • Best for explaining the next layer beyond single-action guardrails.
