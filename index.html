01 / SELECTED WORK

Ideas are good.
Working code is better.

Two open-source projects. Two questions about what an AI agent should be allowed to do.

Python package · v1.6.9 Beta01

Agent Circuit BreakerACB

“Should this agent action execute?”

Deterministic checks for commands, files, SQL, and MCP tools. A stateful runtime gate adds exact approvals and durable execution records for trusted agent integrations.

Proposed action→Policy check→Decision
  • Deterministic checks; no model call required
  • CLI, Python API, MCP proxy, and trusted runtime
  • Single-use approvals and durable local run state

Horizon Agent ContainmentHAC

“What can this agent become capable of?”

A stateful containment engine for long-running agents. Track data lineage, authority, and relationships to detect forbidden capabilities as they emerge.

Secret→Transformed data→Upload blocked
  • Provenance survives transformation and encryption
  • Explicit delegation and security invariants
  • Working Python engine with documented scenarios
